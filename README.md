# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, product performance, and key business insights.

The project uses Python for data analysis and preprocessing, SQL/PostgreSQL for data querying and analysis, and Power BI for interactive data visualization.

## 🎯 Project Objectives

- Analyze customer purchasing behavior
- Understand customer preferences and buying patterns
- Analyze product and category performance
- Identify important business insights
- Perform data analysis using SQL
- Create an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- SQL
- PostgreSQL
- Power BI
- Data Visualization

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis using Python
4. SQL-based Data Analysis
5. Business Insights Generation
6. Power BI Dashboard Development
